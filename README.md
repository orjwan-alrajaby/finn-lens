# finndings

Finn Lens: a browser extension that helps you choose a FINN car subscription by chatting with it. It judges the cars on finn.com against what you told it, puts its verdict on each card, and makes the case for its pick.

The extension lives in [`browser-extension/`](browser-extension/README.md).

An independent project by Orjwan Al-Rajaby — the idea, the research into finn.com and its data, the product's direction and decision model, and the first versions are Orjwan's; from September 2026 it was built with Claude Code, Anthropic's AI coding assistant. Not affiliated with FINN. More in [Who built it](browser-extension/README.md#who-built-it).
